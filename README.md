# AgroExample — Modern Organic Production

A complete presentation of a modern organic family farm and estate. This project is an example of a corporate multi-page website with a clean, airy design focused on local production, BIO standards and ecological economy.


---

## About the AgroExample project
The website represents a sustainable agro-business that combines family traditions with modern technological processes. It serves to present plant micro-production, animal production respecting *animal welfare* and promote local sales directly from the farm.

## Website architecture and functions
The project does not consist of just one subpage, but is a full-fledged web presentation divided into logical units:

- **Introduction (`index.html`):** The main landing page with an overview of key benefits (100% Organic, Own production, Freshness from the farm), customer references and an overview of farm statistics.
- **About us (`o-nas.html`):** Company history, introduction to the farm's philosophy and values ​​on which the family business is based.
- **Our activities (`sluzby.html`):** Detailed analysis of the processes of plant production (with regard to the soil microbiome and rotational farming) and livestock breeding.
- **Yard sales (`predaj.html`):** Overview and offer of fresh local products that farmers distribute without intermediaries.
- **Contact (`kontakt.html`):** Contact details, phone numbers, opening hours and a map for direct navigation to the farm.

## Design elements (UI/UX)
- **Green identity:** The color palette reflects nature, freshness and organic origin of food.
- **Trustworthiness (Social Proof):** Implemented customer reviews section with ratings from chefs and local families.
- **Trust Badges:** The website visually presents certificates and awards (*BIO Product SK, Slovak Gold, Eko Manufaktúra*), which underline premium quality.
- **Full Responsiveness:** The layout is completely flexible and fully optimized for comfortable reading on smartphones, tablets and monitors.

## Technologies used
The project emphasizes high loading speed, code cleanliness and does not use any redundant Javascript frameworks (so-called Lightweight Vanilla Stack):

- **HTML5** – Semantic layout of multiple linked subpages.
- **CSS3** – Modern layout using Flexbox and CSS Grid, sophisticated card design, custom animations and responsive `media queries`.
- **Vanilla JavaScript** – Used to operate the responsive navigation menu and interactive UI components.
